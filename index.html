Goal: See how your device reaches the first router.

Chapter 03 / 08

Message, Meet Pieces

Goal: See why data travels in smaller pieces.

Networks carry data in packets. Real sizes vary, and a packet usually carries many bytes plus headers. Reliable delivery can detect missing data and restore the correct order.

Quick prediction

If piece 3 is lost, reliable delivery identifies the gap and sends that piece again; the receiver does not guess the data.

Chapter 05 / 08

Pick a Path

Goal: See how routers move a packet one step at a time.

Each router reads the destination IP address and chooses a next hop using its current routing information. After a failure, routing needs time to converge on another available path.

TakeawayNo router needs to know the entire physical journey.

Chapter 06 / 08

Two Delivery Styles

Goal: Compare secure web transport over TCP and QUIC.

TCP provides reliable, ordered bytes. QUIC runs over UDP but adds its own reliable delivery, encryption, and independent streams. HTTP/3 uses QUIC; HTTP/1.1 and HTTP/2 commonly use TCP with TLS.

What about plain UDP?

UDP itself is a small, connectionless transport. An application can value timeliness over recovery or build additional behavior on top—as QUIC does.
